Usage: mrd [options] [commands]

Description:

  Command line tool for reading and modifying Music Routes data

Commands:

  add individuals <name>
    add an individual with an ID derived from the name

  add tracks <name> <metadata-json>
    add a track with required, non-empty artists and releases arrays
    example: add tracks "Song" '{"artists":[{"names":["Artist"]}],"releases":[{"names":["Album"]}]}'
    metadata may include an explicit _id; otherwise the track name is used

  link <collection1> <id1> <collection2> <id2>
    link an individual and a track (use singular individual and track)

  search <collection> <name>
    return JSON for all entries in collection that have the specified name
    searchable collections: tracks, individuals

Options:

  -i, --inputDir
    directory from which data JSON files will be read

  -o, --outputDir
    directory to which data JSON files will be written
